Constructor:

TpMenu({type:'menu', id:'rf', image:'images/ico_sms.gif', title:'Red Flag', onclick:'onMenuClick', width:'150px'}); 
{type:'menu', image:'images/ico_sms.gif', title:'Red Flag', onclick:'onMenuClick', width:'150px'}

	type:'menu'
	type can be either menu or separator
	
	id: 'rf'
	Id given by the user
	
	image:'images/ico_sms.gif'
	image for menu
	
	title:'Red Flag'
	Text for menu
	
	onclick:'onMenuClick'
	Action to be performed on click, when even is called it is called onMenuClick(originalMenuObject, optionsPassedInShow)
	
	width:'150px'
	Width of menu, you can define width to any one menu in the given menu group, that will be applied to all list
	
	isToggle: true/false
	Is this menu is toggle menu
	by default false
	
	toggleState: true/false
	What is toggle state true/false
	by default false
	
	disabled: true/false
	menu item is disabled - true or false
	by default false
	
	hidden: true/false
	menu item is hidden - true or false
	by default false
TpMenu Methods:

addItem(tpMenu) 
	menu1.addItem(menu2)
	adds menu2 to menu1 as submenu


TpMenuHandler(menu,{}) 
	menu
		TpMenu object

	{} options can be any of following

		menuClass:'divTpMnu'
		default class for menu Div is 'divTpMnu'
		
		tableClass:'tblTpMnu'
		default class for menu item is 'divTpMnu'
		
		selectedClass:'selectedTpMenu'
		default class for selected menu item is 'divTpMnu'
		
		subMenuImg:'images/ico_sub_arrow.gif'
		This is image of submenu arrow. default is 'images/ico_sub_arrow.gif'
