Creating Control

//Create an array of options 
//value and names
var opts = new Array();
opts[0] = new SelectOption('1','Electronics And Telecommunication Engineering');
opts[1] = new SelectOption('2','Mechanical Engineering');
opts[2] = new SelectOption('3','Computer Science');
opts[3] = new SelectOption('4','Electrical Engineering');
opts[4] = new SelectOption('5','Electronics" Engineering');
opts[5] = new SelectOption('6','Metallurgy');
opts[6] = new SelectOption('7','Civil');
opts[7] = new SelectOption('8','Production');
opts[8] = new SelectOption('9','Instrumentation');
//Instantiate the control 
var x = new SelectBox(opts,'1','icon_down_arrow.gif',{namesonly:false, width:'180px', size:18});
x.setContainerTemplates('<div class=\"header\">Degrees</div>','<div class=\"footer\"></div>'); 	////Optional step
x.setOnChangeHandler('onChange');		////Optional step
document.write(x.getHtml());
x.init();
Constructor:

SelectBox(optionsArray,initialSelectedId,imagePath,{namesonly:false, width:'180px', size:18}) 
optionsArray
	Array of options

imagePath
	Path of arrow image

imagePath
	Id of the Image for arrow button

{namesonly:false, width:'180px', size:8}
	These are the different options you can specify while initializing the control

	namesonly:false
		if you don't have values for the options in that case this is true.

		For example, in above example you have list where you have ids for each option,
		then you create the option as below and set namesonly:false
		new SelectOption('2','Mechanical Engineering');

		in case you have just list, specify value as null and set namesonly:true
		new SelectOption(null,'Mechanical Engineering');

	width:'180px'
		width of the control

	size:8
		Size of the drop down box, determoines number of options visible at a time in the dropdown,
		also required for pageup and pagedown, default is 10.

	textboxclass:'dropdowntextbox'
	 	default class for textbox is 'dropdowntextbox'
	textboxfocussedclass:'dropdowntextboxfocused'
	 	default class for textbox is 'dropdowntextboxfocused'
	imageclass:'dropdownimage'
	 	default class for textbox is 'dropdownimage'
	containerclass:'containerdiv'
	 	default class for textbox is 'containerdiv'
	layerclass:'dropdowndiv'
	 	default class for textbox is 'dropdowndiv'
Methods:

setContainerTemplates(headerTemplate,footerTemplate) 
	Adds header and footer to container div,
	should be defined before getHtml()
getHtml() 
	returns the html for control
init() 
	initiates control, make sure you call getHtml() before this.
setOnChangeHandler(functionName) 
	Assign function which is called on change event of the box
	x.setOnChangeHandler('onChange');
	function onChange(selectedId){
		alert(selectedId);
	}
getSelectedIndex() 
	returns selectedIndex
	default 0, null if dropdown is empty
getSelectedId() 
	return selected Id
	default 0, null if dropdown is empty
getText(sectedIndex) 
	return text at the index passed
	default 0, null if index out of bound
clearDropDown() 

reInitialize(opts, initialSelectedId)

	Reinitialize the dropdown with given options and preselect the element with id same as initialSelectedId


getIndexWithId(id)

	return the first index of the given id


setSelected(index)

	select the element at specified index


disable

	disable the control


enable

	enable the control
